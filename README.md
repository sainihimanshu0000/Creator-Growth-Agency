# Creator Growth Agency

Marketing website for **VANTAGE** — a creator & brand growth agency.

## Run locally

```bash
cd client
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Admin inbox:** [http://localhost:3000/admin](http://localhost:3000/admin)  
Set `ADMIN_PASSWORD` in `client/.env.local` (see `.env.example`).

Full docs: [`client/README.md`](client/README.md)

## Customize

Edit `client/src/config/siteConfig.ts` for company name, emails, stats, team, services, and form endpoint.
